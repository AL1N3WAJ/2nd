# 2nd Year Physics Tracker

A mobile-friendly, responsive syllabus tracker for PHYS 201-207.

## Files
- index.html
- style.css
- script.js
- manifest.json

## GitHub Pages
1. Create a repository.
2. Upload these files to the root.
3. In repo settings, enable GitHub Pages from `main` / root.
4. Open the generated Pages URL.

## Features
- Responsive layout
- Dark/light theme
- Search
- Progress tracking
- PYQ and notes Google Drive links
- Planner saved in browser
- Export backup JSON
