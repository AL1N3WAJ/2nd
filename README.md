# Physics 2nd Year Master Tracker

An offline-ready, hardware-accelerated academic dashboard customized specifically for the 2nd Year B. Sc. Honours program at the University of Chittagong.

**Live Site:** [https://al1n3waj.github.io/2nd/](https://al1n3waj.github.io/2nd/)

## Core Architecture
- `index.html` — Clean interface utilizing semantic HTML5 containers and interactive template views.
- `style.css` — High-contrast deep space dark mode matrix optimized with native flex/grid styling variables.
- `script.js` — Client-side database indexing comprehensive lecture sequences and textbook PDF queries.
- `manifest.json` — PWA configuration layout allowing independent application sandboxing on mobile home screens.

## Features
- **University Syllabus Mapping:** Covers comprehensive theoretical papers from PHYS-201 down through PHYS-207, mapping out specific derivation parameters rather than generic subject names.
- **Global Open Courseware Openings:** Integrated learning connections tracking materials across Harvard University, MIT OpenCourseWare, Stanford Engineering, Yale, and NPTEL networks.
- **Direct Cloud Folder Integrations:** Explicit action buttons mapped on each module card link to your shared repository for fast local checks on Notes and Past Year Questions (PYQs).
- **Responsive Checklist Grid:** Structural layout cleanly separates long sub-unit parameters into distinct grid structures on wide monitors to maximize spatial utility.
- **Mastery State Indicators:** tracks ongoing progression benchmarks, applying isolated green color-glow highlights (`⚛️ 100% Mastered`) as soon as target structures are fulfilled.
- **JSON Backup Exports:** Full internal cache metrics export choices protecting your checkbox states across systems without a database account.
